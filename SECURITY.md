# Security

HyperNix is operated by one person on one host, and its repositories are private.

To report a vulnerability in anything described on the organization page, use **Report a vulnerability** on this repository's Security tab (private vulnerability reporting is on), or contact [@nixfred](https://github.com/nixfred) on GitHub. Please do not open a public issue for a security problem.

What is in scope: the design described in the organization profile (the landing gate, the network guard, the microVM edge, the approval and key model). Reports that include a way to reproduce are the most useful.
